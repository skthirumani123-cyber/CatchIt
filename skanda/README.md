# CatchIt 🚌

### Real-Time Bus Tracking System

CatchIt is a real-time bus tracking system designed to help passengers
find buses, track their location, and reduce waiting time.

## 🌐 Live Website

https://catchit-sd63.onrender.com

## 👥 User Roles

- Passenger
- Bus Operator
- Administrator

## 🔄 Working Flow

### Passenger Flow

Login/Register
↓
Passenger Dashboard
↓
Search Bus
↓
Select Bus/Route
↓
View Bus Location
↓
Track Bus
↓
View Estimated Arrival

### Operator Flow

Login
↓
Operator Dashboard
↓
Select Bus
↓
Start Trip
↓
Share/Update Bus Location
↓
Passenger Can Track Bus
↓
End Trip

### Admin Flow

Admin Login
↓
Admin Dashboard
↓
Manage Users
↓
Manage Buses
↓
Manage Routes
↓
Monitor System
↓
View Reports

## ⚠️ Known Issues

- Free hosting may take some time to wake up after inactivity.
- Real-time tracking depends on the availability of location updates.
- Some features may require further testing on different devices.
- GPS/location accuracy may vary depending on the device and network.
- The project is currently under development.
